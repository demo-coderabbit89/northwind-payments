# Northwind Payments (demo)

A small FastAPI payments service used to demonstrate AI code review with CodeRabbit.
Northwind Financial is a fictional company.

```bash
pip install -r requirements.txt
pytest -q
uvicorn app.main:app --reload
```

Operational notes live in [docs/runbook.md](docs/runbook.md).

Standards for contributors (human or AI agent) live in [AGENTS.md](AGENTS.md).
